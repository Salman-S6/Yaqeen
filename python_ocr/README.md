# محرك OCR لمشروع يَقِين

هذا المجلد يمثل جزء **Python OCR Engine** من مشروع **يَقِين**، وهو مسؤول عن قراءة صورة الهوية الشخصية السورية واستخراج البيانات الأساسية منها باستخدام نموذج Gemini.

يعمل هذا الجزء كخدمة معالجة ذكية يمكن استدعاؤها من الطرف الخلفي Laravel أو تشغيلها مباشرة من سطر الأوامر لاختبار استخراج البيانات من صورة هوية.

---

## فكرة المجلد

الغرض من هذا المجلد هو استقبال مسار صورة هوية شخصية، إرسال الصورة إلى محرك OCR، ثم إرجاع البيانات المستخرجة بصيغة JSON منظمة.

البيانات التي يحاول المحرك استخراجها هي:

- الاسم الأول
- الكنية / النسبة
- اسم الأب
- اسم ونسبة الأم
- محل وتاريخ الولادة
- الرقم الوطني

---

## التقنيات المستخدمة

يعتمد المجلد على:

- **Python**: لغة تنفيذ محرك OCR.
- **Google Gemini API**: نموذج الذكاء الاصطناعي المستخدم لقراءة الهوية.
- **google-genai**: مكتبة الاتصال مع Gemini.
- **Pillow**: فتح الصور وتحويلها إلى صيغة مناسبة للمعالجة.
- **Pydantic**: تعريف شكل البيانات المتوقع من المحرك والتحقق منها.
- **python-dotenv**: قراءة مفتاح API من ملف `.env`.

## إعداد ملف البيئة `.env`

أنشئ ملفًا باسم:

```text
.env
```

داخل مجلد `python_ocr`.

في الكود الحالي داخل `ocr.py` يتم قراءة المفتاح من المتغير:

```env
ACTIVE_API_KEY=ضع_مفتاح_Gemini_هنا
```

> ملاحظة مهمة: ملف `.env.example` الموجود حاليًا يحتوي على `GEMINI_API_KEY`، بينما الكود يقرأ `ACTIVE_API_KEY`. لذلك إما أن تضع المفتاح باسم `ACTIVE_API_KEY`، أو تعدّل الكود ليقرأ `GEMINI_API_KEY`.

مثال عملي:

```env
ACTIVE_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxx
```

لا ترفع ملف `.env` إلى GitHub لأنه يحتوي على مفتاح خاص.

## شرح أهم مكونات `ocr.py`

### 1. تحميل المتغيرات البيئية

```python
load_dotenv()
```

يتم استخدامها لقراءة القيم الموجودة داخل ملف `.env`، وخصوصًا مفتاح Gemini API.

---

### 2. نموذج البيانات `SyrianIDModel`

```python
class SyrianIDModel(BaseModel):
```

هذا النموذج يحدد الحقول التي يجب أن يرجعها Gemini من صورة الهوية.

الحقول المطلوبة:

```python
first_name
last_name
father_name
mother_name
birth_place_and_date
national_number
```

وجود هذا النموذج يجعل النتيجة منظمة بدل أن يرجع Gemini نصًا عشوائيًا.

---

### 3. تنظيف الرقم الوطني

```python
@field_validator('national_number')
```

هذه الدالة تنظف الرقم الوطني بعد استخراجه، حيث تقوم بـ:

- تحويل الأرقام العربية إلى أرقام إنكليزية.
- حذف أي رموز أو فراغات غير رقمية.
- إضافة صفر في البداية إذا كان الرقم 10 خانات فقط.

هذا مهم لأن الرقم الوطني السوري قد يبدأ بصفر، وبعض النماذج قد تحذف الصفر الأول أثناء القراءة.

---

### 4. خدمة OCR

```python
class YaqeenOCRService:
```

هذا الكلاس يحتوي على منطق الاتصال مع Gemini ومعالجة صورة الهوية.

عند إنشاء الكلاس يتم تجهيز:

```python
self.client = genai.Client(api_key=self.api_key)
self.model_name = 'gemini-2.5-flash'
```

أي أن المحرك يستخدم نموذج:

```text
gemini-2.5-flash
```

---

### 5. دالة معالجة الهوية

```python
def process_id_card(self, image_path: str)
```

هذه الدالة تنفذ الخطوات التالية:

1. التحقق من وجود الصورة.
2. فتح الصورة باستخدام Pillow.
3. تحويل الصورة إلى RGB إذا لم تكن كذلك.
4. تجهيز Prompt عربي صارم يطلب من Gemini قراءة الهوية بدقة.
5. إرسال الصورة والـ Prompt إلى Gemini.
6. إجبار Gemini على إرجاع JSON حسب `SyrianIDModel`.
7. تحويل النتيجة إلى JSON وإرجاعها.

## التكامل مع Laravel

يمكن للـ Backend المبني بـ Laravel استدعاء هذا الملف باستخدام أمر مثل:

```php
python python_ocr/ocr.py storage/app/uploads/id-card.jpg
```

ثم قراءة الخرج JSON ومعالجته داخل Laravel.

يفضل في التكامل الحقيقي:

- تمرير مسار الصورة المرفوعة من Laravel إلى `ocr.py`.
- قراءة الخرج من `stdout`.
- إذا كان `success = true` يتم تخزين البيانات المستخرجة.
- إذا رجع `status = error` يتم إرجاع رسالة خطأ مناسبة للواجهة.

## ملاحظات أمنية

- لا تحفظ مفتاح Gemini API داخل الكود مباشرة.
- استخدم دائمًا ملف `.env`.
- لا ترفع ملف `.env` إلى GitHub.
- تأكد أن الصور المرفوعة مخزنة في مسار آمن.
- لا تسمح للمستخدم بتمرير مسار عشوائي من الواجهة مباشرة إلى Python دون تحقق من Laravel.

---

## ملاحظات مهمة حول النسخة الحالية

- المحرك الحالي يعتمد على Gemini API، لذلك يحتاج اتصال إنترنت ومفتاح API صالح.
- لا يوجد في النسخة الحالية تحقق محلي متقدم من أن الصورة هي فعلًا هوية شخصية قبل إرسالها إلى Gemini.
- لا يوجد حاليًا فحص جودة للصورة مثل الإضاءة أو الضبابية أو الأبعاد قبل استدعاء OCR.
- درجة الثقة `confidence_score` ثابتة حاليًا بقيمة `98.5` وليست محسوبة فعليًا من Gemini.
- إذا أردت تقليل استهلاك API، يمكن لاحقًا إضافة دالة تحقق أولية للصورة قبل إرسالها للمحرك.

---

## اقتراح تحسين لاحق

يمكن إضافة دالة مثل:

```python
validate_id_card_image(image_path)
```

قبل استدعاء Gemini، بحيث تتحقق من:

- أن الملف صورة فعلًا.
- أن أبعاد الصورة قريبة من أبعاد بطاقة هوية.
- أن الصورة ليست مظلمة جدًا.
- أن الصورة ليست ضبابية جدًا.
- أن حجم الصورة مناسب.
- أن الصورة تحتوي على تفاصيل كافية.

وبذلك لا يتم استهلاك Gemini API على صور غير مناسبة.

## الخلاصة

مجلد `python_ocr` هو محرك قراءة الهوية في مشروع **يَقِين**.  
وظيفته تحويل صورة الهوية الشخصية إلى بيانات منظمة يمكن استخدامها داخل النظام لتسريع معالجة الطلبات وتقليل الإدخال اليدوي من قبل الموظف.

هذا الجزء يمثل طبقة الذكاء الاصطناعي في المشروع، ويتكامل مع Laravel Backend لتخزين البيانات المستخرجة وربطها بطلبات المواطنين.
